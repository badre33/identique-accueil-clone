# Charte graphique officielle (PDF reçu mai 2026)

## Tagline officielle
"La stratégie qui s'exécute." + signature "Revenue Performance Consulting"

## Tonalité
"Minimal. Monochrome. Sans compromis."
Le site doit communiquer l'autorité d'un cabinet de performance, pas d'une agence créative.

## Typographie — UNIQUE
**Montserrat** uniquement, toutes graisses (300 → 900).
- H1 : Black 36pt
- H2 : Bold 24pt
- H3 : SemiBold 18pt
- Body : Regular 13pt
- Caption : Medium 7pt UPPERCASE
JAMAIS de mix de polices. JAMAIS de serif.

## Palette officielle
- **Noir #000000** : 60% surface, logos, titres, fonds sombres, texte principal
- **Blanc #FFFFFF** : logo inversé, fonds clairs, texte sur sombre
- **Échelle de gris** : 90/80/60/40/20/10/5% (#1A1A1A → #F2F2F2)
- **Rouge CTA #C8102E** : UNIQUEMENT pour boutons d'action — pas dominant
- **Gold #B8935A** : accents premium uniquement — pas dominant

## Application site web (officielle)
**Dark theme dominant avec accents rouge/gold pour CTAs.**

## Interdits absolus
- Bleu, violet, dégradés, couleurs pastel
- Mélanger plusieurs polices
- Rouge ou gold comme couleur dominante
- Effets, ombres, contours sur logo
